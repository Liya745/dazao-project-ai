# Maven 模块重构与验证

日期：2026-10-30。基线提交 `61d2a9d005cbd42501791800c669430cf2ca5586`，工作分支 `codex/maven-modules`。

## 改动

根工程改为父 POM，集中管理版本并聚合 `dazao-common`、`dazao-system`、`dazao-framework`、`dazao-ai`、`dazao-character`、`dazao-admin`。参考若依的模块组织方式，没有复制框架代码、引入新业务功能或更新依赖版本。模块职责与依赖见根 README。

- `ApiException` 从 Web 包移到 common，业务和模型适配不再反向依赖 Web 包。
- `UserService` 接管注册、认证查询与登录身份解析，角色仓库不再查询账号，也不依赖 `Principal`。
- `ConversationService` 接管上下文、并发、供应商回调和轮次持久化；admin 负责 HTTP/SSE 传输。保留共享请求预算、快照、锁定白名单、owner 校验和原有事务。
- 配置、建表语句、启动类及集成测试归入 admin；只有 admin 使用 Spring Boot repackage，其余模块是普通 Jar。
- 更新 `run.ps1`、`deploy/prepare.ps1`、README、部署说明与 AGENTS 中的路径；`build.ps1` 的根 reactor 命令仍适用，无需修改。递归忽略各模块 `target/`。
- 数据表、配置内容、前端源码、API 格式、模型依赖与原有运行数据路径不变，不需要数据迁移。

## 本地获取

本次分支不自动合并到原业务分支。首次获取：

```powershell
cd E:\JavaWeb-java-items\dazao-project-ai
git fetch origin
git switch --track origin/codex/maven-modules
./build.ps1
./run.ps1
```

若已存在本地 `codex/maven-modules`，切换该分支后使用 `git pull --ff-only`。保留本地未提交工作，不使用强制 checkout 或 reset。IDE 重新加载根 `pom.xml`；普通 Jar 为 `dazao-admin/target/dazao-character-0.1.0-SNAPSHOT.jar`。
