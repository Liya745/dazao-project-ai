## 实现

后端：Java 17、Spring Boot 3.5.16、Spring Security、Spring JDBC、H2 和 LangChain4j OpenAI 1.3.0。前端：Vue 3.5.44、Vite 8.3.4、plugin-vue 6.0.10，固定版本并保存 npm 锁文件。

- 注册/登录/退出使用会话 Cookie 与 CSRF，密码使用 BCrypt。
- 角色生成采用 JSON 输出、字段白名单、服务端校验与合并；所选且未锁定的字段才可写回。
- 编辑、保存、搜索、复制、删除和 Character Card V2 JSON 导出。
- 版本冲突返回 409；角色更新不改变已有会话的快照。
- POST SSE 回复、成功和失败轮次持久保存；失败记录不进入下一次模型上下文。
- 请求额度、模型输出上限、超时、同会话互斥及总并发限制。
- Vue 生产构建嵌入可运行 Jar，提供桌面与手机布局。
- `build.ps1` 安装锁定前端依赖并干净构建、测试和打包；`run.ps1` 启动已有 Jar。

账号、角色和会话属于独立新项目，不读取旧社区数据库。头像为名字标记，外观暂存文本。本阶段未实现图片生成、知识检索、长期记忆、角色卡导入、聊天平台接入和公网部署。
